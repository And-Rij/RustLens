# RustLens — вимоги

<!-- impeccable:product-schema 1 -->

## Platform

web

Інтерфейс на вебтехнологіях у desktop-застосунку Tauri. Перша цільова ОС — Windows; Linux — майбутній напрям.

## Stack

Побажання користувача: Rust + Tauri, React + shadcn/ui. Пропонована основа: Tauri 2, TypeScript і Vite. Локальні моделі через вже встановлену Ollama.

## Users

Основний користувач вивчає англійську з репетитором і хоче грати англійською, перекладати незрозумілі речення без постійного переходу до іншої програми та повторювати власний матеріал.

## Product Purpose

Поєднати переклад у грі зі збиранням матеріалу для практики. Успіх першої версії: прочитати й перекласти фрагмент у грі, знайти його після перезапуску та імпортувати вибраний матеріал в Anki.

## Operating Context

- Англійська → українська.
- Виділення прямокутником; невелике віконце результату поруч.
- Потрібна перевірка повноекранних ігор.
- Основна тестова гра — Limbus Company. Інші ігри поки не потрібні.
- AMD Ryzen 5 7500F, NVIDIA RTX 5060 Ti 16 GB, 32 GB RAM.
- Користувач підтвердив наявність Gemma 4 та TranslateGemma; поточні теги локально перевірені: `gemma4:12b`, `translategemma:12b`.
- Експорт файлом для імпорту в Anki підходить для першої версії.
- Anki встановлено й запущено; AnkiConnect доступний локально. Пряме додавання карток можна реалізувати наступним невеликим блоком після файлового експорту.
- Базовий Rust і знайомство з crates уже пройдені на буткемпі. Реалізація відбувається разом, короткими перевіреними блоками; час обмежений.

## Capabilities and Constraints

Перша версія: вибір області екрана, OCR, локальний переклад, постійна історія, експорт в Anki.

Майбутні можливості: Obsidian, пояснення англійською, приклади, вимова, мініігри на власному словнику та Linux.

Локальне середовище: Windows 11 25H2, build 26200.9168 (визначено за реєстром і таблицею Microsoft). Не вирішено: режими відображення Limbus Company на цьому комп'ютері, додаткові режими (MIT; публічний репозиторій And-Rij/RustLens обрано 2026-10-14). Збереження скриншотів не входить до підтверджених вимог.

## Evidence on Hand

Початкова папка документації містила порожній Git-репозиторій. 2026-10-13 користувач створив каркас Tauri 2 + React + TypeScript + Vite у `C:\Projects\Rust\RustLens`; документацію скопійовано туди. Git ініціалізовано в основній папці; remote — https://github.com/And-Rij/RustLens.git. Захоплення й виділення реалізовано; користувач підтвердив fullscreen Limbus Company. OCR і переклад підтверджені користувачем у грі, повідомлений час — 0,9–3 с. Постійна SQLite-історія й експорт Anki реалізовані та перевірені тестами; Anki-файл імпортовано двічі у тимчасову колекцію без дублікатів. 2026-10-14 користувач підтвердив роботу нового блоку й появу матеріалу у власній Anki. Ollama API відповідає; виконано один реальний тест перекладу, результати в `docs/ENVIRONMENT.md`.

## Product Principles

- Реальна користь під час гри визначає пріоритети.
- Найменший завершений сценарій перед розширенням навчальних функцій.
- Локальний переклад і дані користувача за замовчуванням.
- Кожний етап має демонстрацію, критерії готовності й актуальну документацію.
- Готові компоненти інтерфейсу та зрозумілі модулі Rust прискорюють реалізацію.
