# Перевірка в Limbus Company

Основна гра для першої версії — Limbus Company. Додаткові ігри поки не потрібні. Користувач підтвердив правильне обрізання й роботу першого блоку у повноекранному режимі. Користувач також підтвердив роботу OCR/перекладу й повідомив 0,9–3 с на запит. 2026-10-14 користувач підтвердив роботу блоку історії/експорту та появу матеріалу у власній Anki.

## Перед перевіркою

Зафіксувати версію Windows, роздільну здатність, масштабування, монітор, версію гри та доступні режими відображення. Повноекранний режим з меню гри позначати його фактичною назвою; exclusive/borderless визначати окремо, коли є докази.

Використовувати англійський діалог, який можна читати без поспіху, та звичайний ігровий інтерфейс. Захоплювати кадр до показу вікна виділення; гра при цьому продовжує працювати.

## Матриця перевірок

| Перевірка | Очікуваний результат | Стан |
| --- | --- | --- |
| Гаряча клавіша з фокусом у грі | Починає захоплення одного кадру | Не перевірено |
| Віконний режим | Кадр містить текст гри; виділення працює | Не перевірено |
| Повноекранний режим з меню гри | Кадр не чорний; вибраний текст збігається з кадром | Підтверджено користувачем для першого блоку |
| Borderless, якщо доступний | Виділення й результат видимі | Доступність не уточнено |
| Exclusive fullscreen, якщо доступний | Захоплення та віконце перевірені окремо; зміна режиму/фокусу записана | Доступність не уточнено |
| Виділення діалогу | У фрагмент потрапляє тільки вибрана область | Правильне обрізання підтверджено користувачем |
| Невеликий текст інтерфейсу | Помилки розпізнавання можна виправити | Не перевірено |
| Escape | Закриває виділення/результат і дозволяє повернутися до гри | Не перевірено |
| Віконце біля краю монітора | Повністю залишається на екрані | Не перевірено |
| Повторний запит | Старий переклад не підміняє новий | Не перевірено |
| Гра + TranslateGemma | Час запиту та навантаження | Користувач: 0,9–3 с; GPU/FPS не виміряні |
| Перезапуск RustLens | Історія перекладів доступна | Не перевірено |
| Anki | Вибрані фрази імпортуються з правильними Front/Back | Користувач підтвердив появу матеріалу; поля/повторний імпорт перевірені також у тимчасовій колекції |

Підтвердження користувача: «Правильно, і працює в повноекранному режимі». Exclusive/borderless, DPI, версія гри та Windows у цьому повідомленні не уточнені.

## Докази готовності

Для кожного підтримуваного режиму записати фактичний результат, відтворювані кроки та обмеження. Достатньо кількох коротких фрагментів з різними шрифтами; вимірювання продуктивності записувати окремо для першого та прогрітого запиту.

Файловий імпорт підтверджено користувачем: «Перевірив, працює, в анкі появилося». AnkiConnect перевірено лише на доступність API; пряме додавання через нього ще не реалізоване.
