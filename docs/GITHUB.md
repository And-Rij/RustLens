# Перша публікація на GitHub

Ліцензію MIT обрано 2026-10-14. Створено публічний репозиторій [And-Rij/RustLens](https://github.com/And-Rij/RustLens). Перший push і виконання CI фіксуються після локальних перевірок.

## Що включити

Код, README, LICENSE, THIRD_PARTY.md, документацію, CI, fixtures, Cargo.lock, pnpm-lock.yaml і OCR manifest. `.gitignore` виключає node_modules, dist, target, завантажені ваги, бази історії та типовий файл експорту. Перед першим комітом переглянь перелік файлів; особисті дані й власні експортовані файли не потрібні в репозиторії.

## Створення репозиторію

1. На GitHub створи репозиторій, наприклад `RustLens`, з обраною видимістю.
2. Залиши опції автоматичного README, .gitignore і license вимкненими: ці файли вже є в проєкті.
3. Для цього проєкту remote уже налаштований: https://github.com/And-Rij/RustLens.git. Публічну видимість і назву погоджено користувачем; перша публікація виконується після локальних перевірок.

Після push відкрий Actions → Windows checks. Локальні перевірки не підтверджують, що GitHub-hosted job вже виконався.

## Інсталятор

`pnpm models:download` → `node scripts/collect-notices.mjs` → `pnpm tauri build --bundles nsis`.

OCR-моделі й повідомлення ліцензій входять до ресурсів. Ollama та модель перекладу встановлюються окремо. Перевір запуск встановленої версії на Windows та переклад, перш ніж публікувати installer як GitHub Release. Компіляція й пакування самі по собі не перевіряють сценарій після встановлення.

Демонстрацію та власні скриншоти інтерфейсу можна додати після вибору прикладу. Історія реалізації й поточні межі перевірки — у ROADMAP.md та GAME_TESTS.md.
