## Після MVP

1. Редактор карток: окреме слово/фраза, контекст і власний переклад.
2. Obsidian: Markdown-експорт без залежності від плагіна.
3. Пояснення й приклади через Gemma; вимова.
4. За потреби AnkiConnect для прямого додавання.
5. Навчальні мініігри на збереженому матеріалі.
6. Linux з окремими перевірками X11/Wayland.
