# Блок 3: історія та експорт в Anki

## Можливості

- Успішні переклади зберігаються у локальній SQLite.
- Розділ «Історія»: 20 записів на сторінці, пошук англійською/українською/назвою моделі, фільтр «Лише для навчання».
- Фрази можна позначити у вікні перекладу кнопкою «Для навчання» або прапорцем в історії.
- Експорт усіх позначених фраз через стандартний діалог збереження файлу.
- Повторний переклад того самого англійського тексту оновлює запис і зберігає позначку. Зміни переносів рядків не створюють дублікати.
- Помилка SQLite показується окремо: успішний переклад залишається доступним.

Історія починає накопичуватися з цього блоку. Зображення фрагментів не записуються в базу.

## Дані й код

На цьому Windows-комп'ютері створено `C:\Users\Andrij\AppData\Roaming\com.andrij.rust-lens\history.sqlite`. Загальний шлях визначає Tauri `app_data_dir`.

`src-tauri/src/history.rs`: таблиця translations, нормалізація ключа фрази, пошук, pagination, позначки та читання вибраного матеріалу. SQL використовує параметри; символи `%`, `_` та `\` у пошуку трактуються буквально. Пошуковий текст нормалізується Unicode lowercase у Rust.

`src-tauri/src/anki_export.rs`: UTF-8, tab-separated файл, HTML-екранування, переноси рядків, теги, нативний save dialog і запис через тимчасовий файл. Експортуються лише позначені записи; позначки після експорту зберігаються.

`src/HistoryPanel.tsx`: історія, пошук з debounce, фільтр, pagination й експорт. Перелік читається сторінками з SQLite, а не завантажується весь у React. Запити захищені від застарілих відповідей.

Для резервної копії закрий RustLens і скопіюй папку історії з усіма її файлами, включно з SQLite WAL-файлами, якщо вони залишилися. Шлях видно у розділі «Історія» → «Файл локальної історії».

## Імпорт у Anki

1. В історії познач потрібні фрази.
2. Натисни «Експорт в Anki» й збережи `RustLens-Anki.txt`.
3. В Anki відкрий імпорт файлу та вибери цей файл.
4. Вибери базовий тип нотатки Basic або його локалізований відповідник і бажану колоду, наприклад RustLens.
5. Перевір відповідність: Front — англійський текст, Back — український переклад, Tags — теги. Заголовки файлу задають Tab, HTML і колонку тегів.
6. Для повторних імпортів використовуй той самий тип нотатки й колоду та зіставлення дублікатів за типом нотатки й колодою. Обери оновлення існуючих нотаток або пропуск дублікатів.

Перший стовпець стабільний для того самого тексту. Українські символи, лапки, переноси та буквальні HTML-символи перевірені імпортом. Збережені фрази варто переглянути перед повторенням; переклад моделі можна виправити у самій Anki.

AnkiConnect для файлового експорту не потрібний. Пряме додавання кнопкою залишається окремим майбутнім блоком.

## Перевірки

- `pnpm build`, `cargo check`, `cargo clippy --all-targets -- -D warnings`, `cargo fmt -- --check` — успішні.
- `cargo test --lib`: 13 пройдених тестів, 3 додаткові інтеграційні/fixture-тести пропущені за замовчуванням.
- SQLite-тест закриває й повторно відкриває базу, оновлює переклад та перевіряє збереження позначки без дубліката.
- Перевірені pagination, Unicode-пошук, буквальні SQL wildcard-символи, помилка неіснуючого запису.
- Перевірені CSV/TSV-поля, HTML-екранування, український текст, порожній експорт, тільки вибрані фрази та повторний запис файлу.
- У запущеному застосунку створена реальна таблиця translations у зазначеній app-data базі; перевірка була read-only.
- Реальний файл створено Rust-експортером та імпортовано встановленою бібліотекою Anki у **тимчасову окрему колекцію**: 2 нотатки / 2 картки; правильні українські поля, HTML і тег rustlens. Повторний імпорт залишив ті самі 2 картки без дублікатів. Колекція користувача не відкривалася.

Повторення перевірки Anki на цьому комп'ютері, з кореня проєкту:

```powershell
$env:RUSTLENS_TEST_EXPORT = (Join-Path (Get-Location) 'src-tauri\tests\fixtures\anki-import.txt')
cargo test --manifest-path src-tauri/Cargo.toml --lib writes_anki_import_fixture -- --ignored
python src-tauri/tests/verify_anki_import.py src-tauri/tests/fixtures/anki-import.txt --anki-packages C:\Apps\Anki\app_packages
```

Другий крок потребує Python, сумісного зі встановленою бібліотекою Anki. На цьому комп'ютері перевірено Python 3.13.12. Інші інсталяції можуть використовувати інший шлях або Anki library у власному Python-середовищі.

Користувач підтвердив роботу другого блоку в грі та повідомив 0,9–3 секунди на переклад. Це користувацьке спостереження, не інструментальне вимірювання GPU/FPS.
